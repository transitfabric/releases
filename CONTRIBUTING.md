# Contributing

This repository holds Transit Fabric release files, the public docs site and the tester leaderboard. Transit Fabric is testing on Bittensor **testnet, subnet 611**. Testnet only.

## What to send as a pull request now

- Documentation fixes and guides (everything under `docs/`).
- Typos, broken links and unclear steps in the quick start.
- Leaderboard corrections. Only maintainers change `docs/leaderboard.json`. If your entry is wrong, open an Issue or a PR and say what should change. A maintainer will merge it.

Merged documentation fixes earn participation points. See the [bounty page](https://transitfabric.xyz/bounty.html).

## Source code is not public yet

There is no source code in this repository, so there is nothing to send a code PR against. If you have a code fix:

1. Open a private security advisory with **Security > Report a vulnerability**.
2. Put the fix in the advisory as a patch. If you want to work on it as a branch, use the temporary private fork that GitHub can create from the advisory.
3. Do not post patches, exploit details or logs with keys in a public Issue or PR.

## Findings and tiers

Security findings and exploits go to private advisories, never Issues. We tier them as Critical, High, Medium or Low. The tiers, points and rules are on the [bounty page](https://transitfabric.xyz/bounty.html) (`docs/bounty.html`).

Ordinary bugs go in a public Issue. Peering requests use the Peering request form.

## Conduct

- Be kind and be direct. No harassment, hate or personal attacks.
- Testnet only. Never use mainnet keys or real TAO.
- Do not disrupt other testers beyond the minimum needed to show a problem.
- Never post private keys, seed phrases, wallet files, IP addresses or hostnames you do not own. Remove them from logs.
- Maintainers may edit or close anything that breaks these rules.
