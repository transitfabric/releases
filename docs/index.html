Transit Fabric testnet 611

Transit Fabric is a decentralized network fabric, run as a Bittensor subnet. It is testing on Bittensor testnet, subnet 611.

Nodes carry overlay traffic for each other (mechanism 0). Route solvers compete to produce the route table the network runs (mechanism 1). Validators measure both and set weights.

Node types: what you can run

A node is one machine on the fabric that carries transit for other nodes. It has its own key and its own overlay address, and it peers with other nodes over BGP. Nodes are paid from network emissions for measured transit. Which kind you run depends on what you have.

Edge, gateway and node

  • A node is the general thing. It carries overlay traffic and never leaves the overlay.
  • An Edge is hardware: a 1U box that connects to an operator's own router. It is one way to run a node.
  • A gateway is a role that a registered data centre operator's node plays. It is the one place traffic enters from, or leaves to, a network that does not run Transit Fabric. It needs its own ASN, proof of it, and a bond.
  • An Edge is not a gateway, and a gateway does not need an Edge.

Validators and solvers are roles, not nodes. Validators measure nodes and solvers and set weights. They are not on the data path. Solvers produce the route table (mechanism 1). They never join the overlay or carry traffic.
