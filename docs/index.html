Transit Fabric testnet 611

Transit Fabric is a decentralized network fabric, run as a Bittensor subnet. It is testing on Bittensor testnet, subnet 611.

Nodes carry overlay traffic for each other (mechanism 0). Route solvers compete to produce the route table the network runs (mechanism 1). Validators measure both and set weights.

Download v0.1.0-tester.2 (testnet pre-release)

Current version: v0.1.0-tester.2. All releases.

Testnet only. Use your own nodes, hotkeys and test TAO. Releases are not signed yet: compare the hash of SHA256SUMS with the one in our announcement before you run anything.
