Transit Fabric testnet 611

Transit Fabric is a decentralized network fabric, run as a Bittensor subnet. It is testing on Bittensor testnet, subnet 611.

Nodes carry overlay traffic for each other (mechanism 0). Route solvers compete to produce the route table the network runs (mechanism 1). Validators measure both and set weights.

Download v0.1.0-tester.5.2 (testnet pre-release)

Already running a node? Update it to tester.5.1 or later before Sat 2026-11-28 14:51 UTC (block 8,544,600): scoring version 2 and automatic peering start at block 8,544,960, about 16:03 UTC. tester.5.1 makes nodes open far fewer TCP connections: kernel nodes re-run install.sh, and containers are recreated, not just restarted. Your key, binding and credit stay. Still on tester.4.3 or earlier? Move it to the rebuilt fleet first.

Current version: v0.1.0-tester.5.2. All releases.

Testnet only. Use your own nodes, hotkeys and test TAO. Releases are not signed yet: compare the hash of SHA256SUMS with the one in our announcement before you run anything.
