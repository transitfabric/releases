Red-team pack

Everything you need to look for ways to earn more than you carry on Transit Fabric (Bittensor testnet, subnet 611), and to show them working. The pack was taken from the source repository at commit 91be12e.

Read the bounty page first: it has the scope, the out-of-scope list, the tiers and the rules. Register once on the claim page so credit goes to your address.

What is in the pack

What Why you want it
Scoring spec (.md) How emission shares are computed, with every parameter and its default. The place to look for something worth gaming.
Measurement spec (.md) What validators probe and test, and how results are pooled.
Receipts spec (.md) How bytes are credited, and what a relay can and can't claim.
Capacity bonds spec (.md) The bonds that back declared capacity.
Identity spec (.md) Node keys, hotkeys, bindings and consents.
Encoding spec (.md) Canonical encoding and domain-separated signatures.
Threat model (.md) Every attack we have written down, its mitigation and its status. Read it before you file.
Whitepaper (.md, PDF) The design in one document.
The simulator bwos-sim, static binaries for Linux x86_64 and aarch64, with checksums and sample output. A walk-through of reproducing a finding in it.
Finding template The format we want findings in. The "Finding" Issue form has the same fields.

The simulator binaries are assets of the GitHub release redteam-pack-91be12e, a pre-release. Download them and check the SHA256SUMS file before you run anything.

What is in scope

The scope, the out-of-scope items and the reward tiers are on the bounty page. In short: the released software, the incentive mechanism as it runs on subnet 611, and the design documents. Testnet only. Never use mainnet keys or real TAO.

How to file

  1. Reproduce it against a named version. Points need a reproduction.
  2. Check the threat model above and known limits. The first valid report wins, and duplicates are closed with no points.
  3. Use the finding template. A bug goes in through the "Finding" Issue form. A security finding or exploit goes in privately, through the advisory or its API. Large artifacts go in as a zip attachment.
