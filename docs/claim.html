Claim credit: register your address

Register once. You sign a short message with a wallet, and we tie your GitHub account to that address, so points and any tips go to the right place. The bounty is still opening soon, and registering now is fine.

Signing moves no funds. This page never creates a transaction.

The page asks your wallet to sign a text message. It makes no network request, sends nothing anywhere, and stores nothing. Use an address you made for testnet. A signed message can't spend anything, but there's no reason to link a wallet that holds real funds.

This uses a browser wallet extension that supports the Polkadot{.js} extension API (the Polkadot{.js} extension, Talisman, SubWallet and others).

4. Send your claim

Open a prefilled Issue

The button opens a new Issue titled "Bounty registration" with these fields filled in. You need to be signed in to GitHub. Anyone can read it, and it holds only the message, your public address and the signature. If you want it private, paste the claim block into a private advisory instead.

Sign with btcli instead

If you'd rather not use a browser wallet, btcli can sign the same message. This was checked with btcli 9.23.2. Run btcli wallet sign --help to see the options in your version.

btcli wallet sign --wallet-name <your wallet> --no-use-hotkey --message '<message from step 3>'
  • --no-use-hotkey signs with the wallet's coldkey, which btcli will ask you to unlock locally. Without it btcli asks which key to use. To sign with a hotkey, use --use-hotkey --hotkey <name>.
  • Get the address first (btcli wallet list, or your wallet) and put it in the message. The message must carry the address that signs. btcli prints it again as "Signer address".
  • Put the signature in the claim block as signature: 0x.... btcli prints it without the 0x, and either form is accepted.
  • Check it yourself with btcli wallet verify --message '<message>' --signature <sig> --address <ss58>. btcli signs the same way as the browser wallet, so both give a signature that the maintainers' verify-claim tool accepts.

Never type a seed phrase, a mnemonic or a private key into this page, an Issue or a chat. Signing happens in your wallet or in btcli on your own machine.
